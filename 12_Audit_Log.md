# Phase 12 — Audit Logging

Implement the Audit Log system.

Record:
- Login
- Logout
- Income Created
- Income Updated
- Income Deleted
- Expense Created
- Expense Updated
- Expense Deleted
- Settings Updated
- Password Changed

Store:
- Action
- Description
- Related Transaction ID
- Date
- Time

Create an Admin-only Audit Log screen.

Features:
- View
- Search
- Date filter

Do NOT allow deletion of audit logs from the UI.

Audit logs should be created automatically by the backend.

The client must not be able to fake the Admin identity or audit information.

Test all important actions.

Then STOP.
