================================================================================
                         API ENDPOINTS
================================================================================

Income Endpoints (All Protected):

POST /api/income
  Input: { date, categoryId, description, amount, paymentMethod, reference? }
  Output: { success, message, data: Income }
  Status: 201

GET /api/income
  Query: page, pageSize, startDate, endDate, categoryId, search, sortBy, sortOrder
  Output: { success, data: { items, total, page, pageSize, pages } }
  Status: 200

GET /api/income/:id
  Output: { success, data: Income }
  Status: 200

PUT /api/income/:id
  Input: { date?, categoryId?, description?, amount?, paymentMethod?, reference? }
  Output: { success, message, data: Income }
  Status: 200

DELETE /api/income/:id
  Output: { success, message }
  Status: 200

GET /api/income/summary
  Query: startDate?, endDate?
  Output: { success, data: { totalIncome, count } }
  Status: 200
