To generate the frontend components, use find/replace:
  1. Copy Income components
  2. Replace "Income" → "Expense"
  3. Replace "income" → "expense"
  4. Replace "INCOME" → "EXPENSE"
  5. Update API endpoints to /expense

================================================================================
                         API ENDPOINTS
================================================================================

Expense Endpoints (All Protected):

POST /api/expense
  Input: { date, categoryId, description, amount, paymentMethod, reference? }
  Output: { success, message, data: Expense }

GET /api/expense
  Query: page, pageSize, startDate, endDate, categoryId, search, sortBy, sortOrder
  Output: { success, data: { items, total, page, pageSize, pages } }

GET /api/expense/:id
  Output: { success, data: Expense }

PUT /api/expense/:id
  Input: { date?, categoryId?, description?, amount?, paymentMethod?, reference? }
  Output: { success, message, data: Expense }

DELETE /api/expense/:id
  Output: { success, message }

GET /api/expense/summary
  Query: startDate?, endDate?
  Output: { success, data: { totalExpense, count } }
